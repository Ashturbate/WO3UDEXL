Repository to track and document the ongoing expansion project for Warriors Orochi 3 Ultimate Definitive Edition.

Scope of the project so far is as follows:

* Entirely new playable characters
* Entirely new costumes (both backported from newer games and entierly new to the series)
* HD renderer on top of the game (reshade but more purpose built)
* Redesigned UI with non PS3/360 scaling
* Increase enemy/ally counts on screen
* Backported/New Stages
* New enemy types
